## For Mathematicians

**Name:** *Timed / Factored / Monotone-Upset Quadtree Automaton Compiler* (BU-FTA over `BTree α k` and `QTree α k`). **Principle.** A finite binary certificate (a bitmask of reachable states per phase, or a list of upset generators) is checked inside the Lean kernel by `decide`. A once-proved soundness meta-theorem turns "certificate accepted" into a statement for all `k : Nat`. Certificates are pure data (`Nat` bitmasks, lists of `Fin`), with no `Prop` fields. A broken certificate makes the checker return `false`, which is proved by `decide`. Engines in the Lean sources (Section 2): The upset engine only needs the generators of the invariant, not all of its elements. The meta-theorem takes monotonicity of `hTop`, `hBot` and `vGlue` as hypotheses. The graph instance proves them symbolically from `Reach.mono` (`hTopExec_mono`, `hBotExec_mono`, `vGlueExec_mono`).

## Main Theorems

| Theorem (in `Challenge.lean`) | Statement |
|---|---|
| `timedBTA_sound` | General Soundness Meta-Theorem for Height-Timed Bottom-Up Binary Tree Automata. |
| `factoredQTA_sound` | For every factored quadtree automaton with an accepted certificate, every quadtree of every height `k` evaluates to a good state (infinite in `k`). |
| `percEval_eq_QNet` | For every height `k` and every Boolean quadtree, the percolation evaluator's connectivity relation on the four boundary ports equals the quadtree-network relation `QNet` (infinite in `k`). |
| `percolation_duality_D33` | For every height `k` and every Boolean quadtree `q`, the pair (evaluation of `q`, evaluation of its complement) lies in the upset generated by the certificate `certG8` and satisfies `superConnGood` (infinite in `k`). |
| `d33_exact_completeness_height2` | Machine-checked finite instance (height 2 only): every planar pair in the certificate upset is realised by one of 33 explicit witness quadtrees. |
| `hilbert_D4_mod15_annihilation` | For every height `k >= 1` and every Boolean quadtree `q`, `hilbertD4Sum q % 15 = 0` (infinite in `k`). |
| `nonvacuity_barrier_witnesses` | Machine-checked finite instance: two explicit height-2 quadtrees (`qtree4OfBits` of 0 and of 32905) with at least 3 components whose complement evaluates to the top element `TOP4`. |
| `sharpness_and_nonvacuity_family3` | Machine-checked finite instances: three explicit binary trees of height at most 1 on which the carry-lookahead summary `claGP` and the residues mod 7 of `valX + valY` take the stated values. |
