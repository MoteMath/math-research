## Scope & Honesty Note

- **No full top-level open cash-prize problem is solved here.** Every file below is either a kernel-checked reduction (`reductions/`) or a complete Lean 4 proof (`proofs/`) of an intermediate reduction hypothesis (`OMA.solution`) contributing toward those open problems.
- Every file was checked locally against the pinned `formal-conjectures` commit (`9097e2f90e66`) with `tools/lint.py` (`ok: true`, zero `sorry`, zero `native_decide`, zero custom axioms; axioms strictly within `propext`, `Classical.choice`, `Quot.sound`).
- These files import `FormalConjectures.*` and `OMAReductions.*` from `GuillaumeBAUD-coder/open-math-agents`, so this archive intentionally has no standalone `lakefile.toml` (verification is performed by `GuillaumeBAUD-coder/open-math-agents`'s CI checker on each linked PR).
